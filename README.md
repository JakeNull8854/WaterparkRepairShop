# Waterpark Repair Shop

**Status: source-only design, not a playable mod.**

A planned single-player mashup with **Waterpark Simulator** as the primary game and **ReStory: Chill Electronics Repairs** as the repair gameplay source.

Players run a dedicated workshop, receive broken waterpark electronics, diagnose and repair equipment, earn money and upgrade tools and workbenches.

Both games are required by the intended design. Integration with either installed game has **not been implemented or tested**. Do not submit this repository as a playable Melty release.
